## 🧭 1️⃣ Overview  
📰 **Angular-Spring-Blog** is a **legacy blog application** built with **older versions** of its core technologies:  
- ☕ **Java 1.8 (JDK 1.8.0_181)**  
- 🌱 **Spring Framework 4.0.1.RELEASE**  
- 🅰️ **Angular 6.1.0**  

The application uses the **Clean Blog** template (Bootstrap 3.3.7) for its UI design and **Hibernate ORM** to manage interactions with a **PostgreSQL** database.  

> ⚠️ This is an older project intended as a learning/reference application and may use legacy patterns and libraries.  

---

## ⚙️ 2️⃣ Features  
✨ **Key functionalities:**  
- 📝 Authors can **create, edit, and delete** their own posts.  
- 🔒 Posts are **author-restricted** — users cannot modify other authors’ posts.  
- 📄 **Pagination** for easy navigation through posts.  

---

## 🧱 3️⃣ Application Structure  

### 💻 3.1 Front-End (`blog-angular-java` folder)  
Built with **Angular 6**, the front-end incorporates the **Clean Blog** Bootstrap template.  
🎨 **Template Source:** [Clean Blog on Start Bootstrap](https://startbootstrap.com/template-overviews/clean-blog/)

---

### 🧠 3.2 Back-End (`spring-blog` folder)  
Developed with **Java 1.8** and **Spring Framework 4.0.1.RELEASE**, the back-end serves **JSON data** to the Angular front-end and manages authentication, posts, and database access via **Hibernate**.
